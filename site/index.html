一个窗口，
调用你拥有的每一个账号。

Baton 让你正在用的 Claude Code 窗口，把重活交给你拥有的其他账号去做。

获取 Baton 看它怎么工作

Baton，48 秒讲清楚。

一段短片：一个窗口，你拥有的几个账号，以及重活怎样交出去。

面板

所有账号，一个面板。

领队、工作账号、各自的额度和正在进行的任务，都在系统托盘里的一个小面板上。

派发

说一句“/baton”，重活交给另一个账号。

在 Claude Code 里说“use baton”，或输入 /baton 加上任务。工作账号会用它自己的额度，运行官方 Claude Code 完成这件活。

做完后，它把报告交回这个窗口，你可以接着和领队聊。

记忆

同一条线索，接着上次的会话继续。

每条工作线索都有一个名字。同一个工作会话会被接着用，哪怕 Baton 因为额度把它挪到了另一个账号。

项目账本记下每个工作账号做过什么，下一个工作账号开工前会先读到它。

线索

  • auth-refactorwork@example.com
  • thesis-codeschool@example.com

账本

  • 10:02auth-refactor · Edit src/auth/session.ts
  • 10:31thesis-code · Run tests
  • 11:08auth-refactor · Run tests

额度

每个账号的额度，一眼看清。

5 小时和每周的用量，读自 Claude Code 自己的 /usage，并显示什么时候恢复。

每个账号都可以设一个默认模型，比如轻活用 Haiku。

安全网

窗口用到上限时，活不会停下。

如果领队账号在任务中途达到套餐上限，Baton 的钩子会注意到，并在后台用下一个就绪的账号接着同一个会话做下去。

做完会通知你。如果所有账号都到了上限，它会等到最早恢复的那一刻再继续。

怎么用

三步开始。

  1. 1

    添加你拥有的账号

    每个账号登录一次。Baton 把它们和你平时的 Claude Code 登录分开保存。

  2. 2

    一键连接

    点“连接”，Baton 给 Claude Code 加上两条钩子、一个工具和一个技能，并先备份你的设置。

  3. 3

    在 Claude Code 里说“use baton”

    把重活交给你的工作账号，它做完会把报告交回来。

原则

少做事，做得清楚。

凭证不离开各自的文件夹

登录始终走 Claude Code 自己的流程，每个账号的令牌只留在它自己的 Claude Code 文件夹里。Baton 不读取、不复制、也不发送你的 Claude 凭证。

只在你的电脑上运行

Baton 只在 127.0.0.1 上运行，不向任何地方发送任何东西。它不代理 API 流量，也不修改 Claude Code 程序。

一键撤销

断开连接会恢复你的 Claude 设置。除非你选择删除，已保存的账号登录会保留。

直说限制

下面一节写清楚了它的边界。

需要知道

它适合谁，以及边界在哪里。

  • Baton 适合合法持有多个自有账号的人，比如个人账号和工作账号。
  • 每个工作账号都用官方 Claude Code，在它自己的登录下运行。Baton 不会合并或共享同一个登录的额度。
  • 每个账号的额度限制与条款依然适用：Consumer Terms 和 Usage Policy，以及组织的条款（如果账号是 Team 或 Enterprise 席位）。
  • Windows 优先。
  • 还没有在桌面 App 的 Code 标签页里遇到真实的套餐限额事件，故障转移路径目前用模拟事件测试。

  • 适用于 Windows（目前只在 Windows 11 上测试过），并且需要已经装好 Claude Code（桌面 App 或命令行 CLI）。

自己构建

在项目文件夹中运行：

npm install
npm start

Baton 是独立工具，与 Anthropic 无关，可配合 Claude Code 使用。
